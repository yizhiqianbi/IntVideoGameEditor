# 内容台

一套空的角色与故事产品。前端和后端分开，目录里没有预置角色、封面、剧情或旧站文案。账号、会话、角色卡、聊天和创作能力都在，内容要从这里重新开始。

## 目录

- `frontend/`：页面和站点入口
- `backend/`：账号、会话、媒体和业务接口
- `shared/`：两边共用的角色、聊天和界面逻辑
- `public/`：站点标记。角色封面不在这里

页面上的产品名是「内容台」。本地接口只连 `127.0.0.1`，不会指向任何已有线上站点。

## 本地运行

```sh
cd frontend && npm ci && npm run dev
cd backend && npm ci && npm run db:migrate:local && npm run dev
```

前端开发地址是 `http://127.0.0.1:5174`。后端开发地址是 `http://127.0.0.1:8787`。

`npm run verify` 会检查目录是否还带着旧品牌，并确认角色目录是空的。
