# 尾语 · PAWTALE

**把日常，说给有尾巴的朋友。**

从 xumeng 的「角色相遇与共同叙事」体验出发，新建的独立全年龄猫狗版本。名字取自「尾巴 + 话语」，英文为 paw + tale。工作名未做商标检索。

## 本地打开

```sh
cd experiments/pawtale
npm run dev
```

打开 <http://127.0.0.1:3026>。当前工作区可直接使用父目录已安装的 Next / React；复制此目录到其他位置后，先执行 `npm install`。

```sh
npm test                 # 行为、内容边界、接口与存储测试
npm run build            # 独立生产构建
npm start                # 本机运行生产版本，端口 3026
npm run verify:original  # 比对本次操作前记录的原文件指纹
```

## 已实现

- 奶油纸色、森林绿、宋体标题与四幅原创猫狗插画；桌面侧栏和手机底部导航。
- 米洛（橘猫书店店长）、阿晴（金毛邮差）、露娜（灰白猫花艺师），各有目标与可参与的开场。
- 居民详情、分类、搜索、收藏，以及自由对话。
- 对话自动保存；单条回复收藏到手记；自行写手记与确认删除。
- 原创成年猫狗居民创建：性格、职业、近期目标、可互动开场，保存前服务端校验。当前使用公共示意插画。
- 故事、收藏、手记和自建居民导出 / 确认恢复备份。
- 故障时保留待发草稿；显示保存失败；减少动态效果与键盘操作支持。

## 模型与内容边界

仅使用本目录 `.env.local` 中显式配置的 `PAWTALE_API_KEY`、`PAWTALE_API_BASE_URL`、`PAWTALE_MODEL`，不会自动发现父项目的环境文件或供应商变量。本次在新目录显式配置了工作区已有的模型服务凭据，因此使用同一供应商账户计量；没有改动原环境文件，没有复制原版角色、提示词、历史或成人设定。密钥文件为本机私有文件，被 Git 忽略，不发给浏览器。

无 `PAWTALE_API_KEY` 时，清楚标记为「本地故事体验」，使用预写分支。已配置模型时发生故障会报错，不静默切换成预写回复。

自由聊天依次经过输入早期检查 → 模型语义检查 → 固定全年龄系统规则生成 → 输出早期检查 → 模型语义检查。回复完整接收、检查后才返回前端，不流式显示未检查内容。角色创建也经过服务端规则与语义检查。客户端不能提交 system 消息、模型选择、成人模式或自由图片地址。

此实现不含 NSFW 模式、成人角色目录、成人图像、旧角色导入、图片 / 视频生成入口。拟人化采用完整猫狗面孔与身体、日常衣服、职业、语言及友谊。

关键词与通用模型复核都存在覆盖局限，不是经过认证的全年龄审核保证。当前为本机体验版本；公开运营前仍需针对所用服务验收语义审核、账号 / 用量限制、举报处理与隐私流程。本版本没有账号、支付、论坛、语音视频或云同步，未向远端部署。

## 隔离范围

所有应用文件放在 `experiments/pawtale/`，截图放在新建的 `output/playwright/pawtale/`。不修改父项目的组件、路由、依赖清单、环境文件、部署配置、角色目录或资源。

浏览器键为 `pawtale.workspace.v1`，没有读取或迁移叙梦浏览器数据。当前历史只在本浏览器保存。模型仅携带最近 40 条消息；本地每位居民最多保留 160 条消息，手记最多 100 条，原创居民最多 30 位。没有实现云记忆或完整长对话记忆。

初始指纹记录覆盖 2,921 个文件，其中原项目范围为 2,886 个文件；额外 35 个文件属于已有的另一个独立项目 `qingyu-web`。核对脚本单独列出该并行项目中的变化，本任务从未写入或回滚这些文件。

## 文件

- `app/page.jsx` / `app/styles.css`：独立 UI 与交互。
- `app/api/chat/route.js`：尾语聊天接口。
- `app/api/characters/route.js`：居民校验接口。
- `lib/characters.mjs`：三位原创居民。
- `lib/chat-service.mjs` / `lib/safety.mjs`：模型适配与内容边界。
- `lib/storage.mjs`：独立存储、恢复校验。
- `DESIGN.md`：视觉与交互方向。
- `ART.md`：内置 imagegen 的最终提示词与资源映射。
- `qa/verification.json`：检查结果与边界。

实际界面与流程以浏览器验证记录为准；模拟供应商测试不等同于真实模型内容覆盖率评估。
