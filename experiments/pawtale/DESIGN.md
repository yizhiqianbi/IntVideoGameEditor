# 尾语 · PAWTALE

名字取自尾巴与话语；英文取 paw + tale，表达有尾巴的朋友与共同写下的故事。此为产品工作名，未做商标检索。

视觉主张：像一本被阳光晒暖的独立生活杂志，以奶油纸色、森林绿、手绘猫狗插画和充足留白，承载轻松而有分寸的陪伴。

内容结构：发现居民 → 居民生活与当前目标 → 一段可以参与的日常 → 回到自己的故事与手记。首页以一幅统一的海边小镇插画定调，三位居民是主要可操作内容。

交互主张：首屏文字与画面轻柔入场；居民插画悬停时有轻微景深；页面与对话切换保持短促的渐入。尊重减少动态效果设置。

角色方向：完整动物面孔与毛茸茸身体，穿着日常服装、具有成年居民的职业与生活。拟人化体现在职业、语言、行动、友谊与合作，不采用人脸加兽耳的性感化呈现。

内容边界：全年龄、无成人角色目录、无成人模式、无露骨或性化生成入口。客户端和 API 使用独立的尾语角色与规则。模型回复先完整接收并检查，再交付前端；不流式泄漏未检查的输出。关键词检查有局限，不能当作经过认证的内容审核系统；公开运营前需要独立的语义审核、滥用限制和人工反馈流程。

状态：故事进度由实际完成的对话轮次表达，不把输入固定兑换为好感。对话和手记保存在本浏览器，当前版本没有云端同步。无凭据时使用有明确标识的本地分支故事；有独立凭据时使用模型，故障时显式报错，不偷偷降级。
