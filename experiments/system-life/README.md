# 生来有系统 · 剧情实验

独立运行的系统流互动小说游戏。角色出生时就绑定系统，在十八岁的都市异能事件中，通过对话、自由行动或选项推动剧情。Agent 判定尝试的结果、生成事件与下一处抉择；引擎校验任务进展，结算预先承诺的奖励。

全部实现和运行数据位于本目录。没有修改原 AI 酒馆的工程文件。本版先把剧情玩起来，页面和运行服务不生成视频。

## 运行

需要 Node.js 22 或以上，无外部依赖。

```sh
cd /Users/pencil/Documents/IntVideoGameEditor/experiments/system-life
npm start
```

打开 http://127.0.0.1:3218。默认只监听本机。都市异能是默认背景，也可以自定义人物、系统、地点、同行者和世界背景。

- **Agent 推演**：只读沿用原工程 `.env.local` 中的文字模型配置，凭据留在服务端；产生模型 API 用量。H3 是视频模型，当前剧情由文字模型推演。
- **编排演示**：本地原创分支故事，包含救援、调查、报告/保密/公开的不同后果，以及失败后的补救。不会冒充模型推理；自由输入只能覆盖演示支持的行动。
- 本目录 `.env.local` 可以覆盖原配置。变量见 `.env.example`，原工程配置不会写入。

## 怎么玩

开局立即发布一个目标，列出可验证条件和固定奖励。点选行动或输入对白、调查方法、救援方案。每幕会展示你的行动、结果依据、人物反应、任务变化及下一步选择的取舍。能力获得后，Agent 会把它带入下一轮判定；演示中也有实际使用新能力的后续任务。

“考虑救人”不等于已经救出人，“给我无限积分”不等于获得奖励。失败可以损失证据、影响人物关系或令任务失败，再继续补救。体力、积分、目标、能力、人物态度、已确认事实、悬念和实际后果都会保存。

每轮流程是：校验版本与行动 → Agent 提出剧情和事件结算 → 引擎校验事件引用、任务条件、资源限制 → 原子保存整幕。失败或不合格输出不会写入本轮，页面允许重试同一行动。重复请求不会重复结算，旧页面不能覆盖新剧情。

## 存档与回溯

新版存档位于 `.data/stories/`，支持续玩、逐幕查看、回到某一幕重新选择、JSON 导出及导入副本。导入时重放每幕事件结算，拒绝与记录不符的积分、奖励、任务进度或固定设定。导入新副本不会覆盖原故事。

第一版数值/视频实验的 `.data/sessions/` 和 `.data/media/` 保留。新版不会覆盖或列出这些存档，也不直接导入旧格式。旧引擎和 H3 适配器保留供后续接回视频；当前入口是新版 `server.mjs`。

## 实现与边界

- `narrative-agent.mjs`：角色行动、当前状态、最近剧情、事实和悬念组成模型上下文，生成结构化事件提案。
- `narrative-engine.mjs`：任务条件、事件引用、单次奖励、状态快照、回溯与存档重放。
- `server.mjs`：本机 HTTP 服务、凭据读取、并发限制、幂等行动和原子存档。
- `GENRE-NOTES.md`：两部小说公开原作章节的机制参考，以及原创都市异能剧情设计。
- `NARRATIVE-CONTRACT.md`：数据格式和 Agent / 引擎接口。

这是可玩的剧情实验。任务与资源有硬约束，事件是否真正符合叙事仍由模型判断，不能保证长篇故事每句话都无矛盾。尚未加入完整战斗模拟、长期知识图谱或视频生成；后续视频应附在已经提交的剧情节点上。
