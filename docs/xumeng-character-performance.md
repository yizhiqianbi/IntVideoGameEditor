# 小说人物、直播与角色朗读

小说工作台新增「人物」页，最多保存 30 位人物。每位人物包含姓名、形象图片、描述、性格与表达、初始场景、台词示例、直播音色与朗读音色。可以手动创建，或复制现有角色卡的这些资料；复制后独立编辑，不回写原角色卡。人物随私人作品保存、恢复和 JSON 备份，旧作品无需补字段。

## 使用流程

1. 小说创作 → 打开作品 → 人物 → 新建人物或从角色卡导入。
2. 选择人物，点击「去直播」或「生成语音」。有未保存修改时先保存，保存失败保留原稿，不跳转。
3. 可勾选当前章节章末最多 2,000 字作为直播剧情参考，默认不勾选。它与初始场景、台词风格分别传递，避免把示例当成已发生事件。
4. 直播人物选择器、角色详情和聊天页也提供人物入口。导入不会自动开播；需要用户检查图片、设定和音色后点击开始。
5. 角色朗读可编辑台词并生成、播放、下载本人私有音频。失败保留台词和已有结果；相同人物、台词与音色命中缓存不重复生成。

直播继续使用 Vidu S2 和现有 Super 权限，音色支持流畅中文默认女声，以及 Tina、御姐、软萌撒娇、邻家元气、温柔、低沉温和、阳光活力、清爽青年与清亮男声等官方 S2 选项。导入明确区分人物背景、当前剧情参考和对白风格；设定限制在 5,000 字符内。覆盖已经修改的直播形象、设定、音色或参考图，以及朗读台词，都需要先确认。

朗读保留 Workers AI MeloTTS 自然中文默认声音，新增 Vidu TTS 的御姐、软萌少女、甜美、成熟与四种青年男声，共九个选项。需要 VIP 或 Super，沿用与聊天语音共享的每日 20 次额度，Super 不受此额度限制。它不克隆人物声音；人物的直播音色与朗读音色分别保存，各自使用对应供应商的真实音色 ID。详见 [角色朗读](xumeng-character-voice.md)。

## 保存与隔离

迁移 `0031_novel_characters.sql` 为 novels 添加 `characters_json`；旧客户端更新时省略字段会保留既有人物，显式空数组才会清空。迁移 `0032_character_voice.sql` 保存私有朗读资产。小说人物遵守现有账号、版本冲突和批量保存检查。

直播和语音工作台按账号挂载。切换账号中止未完成请求并清除前一账号的导入选择，人物列表只读取本人小说。角色图片转为经过大小、格式与解码检查的图像数据，不把本站登录 Cookie 交给 Vidu 或外部图片站。请求可取消并设有超时。

当前导入是人物资料快照。用户在当前角色聊天中点击「当前角色去直播」时，明确携带该会话最近最多八条非等待中的实际对白，以及覆盖完整当前消息且指纹一致的世界快照。仅覆盖旧前缀的快照不作为当前地点、任务或关系；改写、回退后的无效快照同样不传入。普通角色选择仍使用初始场景，小说章末是可选参考而不是已发生事实。不会持续双向同步小说与直播，也不会自动批量读取其他聊天历史。直播工作台修改与朗读台词、播放器结果不承诺在刷新后恢复；保存的小说人物可以重新选择。角色卡直接导入直播还带入受限长度的补充设定与常驻世界书内容，条件触发世界书不参与直播。复制到小说的人物只包含上述可编辑档案字段。

## 本轮验收范围

使用原创私人小说、人物、隔离 D1/R2、模拟 AI 与 Vidu 接口，验证保存失败重试、保存后重开、可选章节参考、导入参数、换人物覆盖确认、语音缓存、失败保稿、私有资源权限及 390 CSS 像素布局。模拟音频为一秒静音 WAV，仅证明播放器加载与播放，不证明真实音色或听感。本轮未创建真实直播或调用付费媒体模型。

正式发布另外核对迁移、前后端版本、网页实际 JS/CSS 字节和未登录语音接口；生产 HTTP 与隔离媒体验收分别归档在 `output/xumeng/character-performance-20261010/`。


2026-10-10 多音色更新：迁移 `0033_character_voice_style.sql` 为朗读资产记录真实 `voice_id`，旧记录默认 MeloTTS；旧小说未填写 `speechVoice` 时仍兼容。界面提供按女声、男声分组的选择器和八个 Vidu 官方免费试听样例，不调用付费生成接口。隔离 API 和实际浏览器验证两种音色保存、刷新、导入、缓存隔离、错误保稿与晚到人物列表不覆盖手选音色。本轮没有调用真实付费 TTS 或 S2，新音色的本人账户生成、听感与直播表现尚未逐项验收。窄屏能力未实际改变页面宽度，本轮不计手机布局通过。发布与证据以 `output/xumeng/voice-styles-20261010/report.json` 为准。
