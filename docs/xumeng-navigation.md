# 叙梦响应式导航

消息页包含三个互斥分类：「故事」承接角色扮演和剧情会话，「聊天」承接 Yume 等直接陪伴聊天，「游戏」直接列出本账号游戏作品，最近游玩记录只参与排序。没有「全部」或独立的「查看游戏」按钮。故事的匹配、定制、预设和导入工具只在故事分类显示。

列表地址分别为 `#chat`、`#chat/chats`、`#chat/games`；`#chat/girlfriend` 自动选中聊天，`#chat/game/private/:id` 自动选中游戏。手机返回按钮回到所属分类，切换分类保留各会话草稿；正在生成故事时需要先停止回复再切换。

收窄首页窗口时，原页头会挤出视口，手机端则隐藏顶部主导航。现使用固定可见的“菜单”入口来收拢功能。

- 1280px 及以上：保留横向主导航。
- 1279px 及以下：在品牌旁显示“菜单”，展开两列完整导航；搜索、VIP、主题继续可用。
- 380px 及以下：保留自有品牌图标，收起文字字标，为菜单与搜索（含清除按钮）腾出空间。
- 手机底部导航继续保留。聊天正文原有返回列表的方式保持不变。
- 短窗口：菜单内部滚动，关闭按钮固定在菜单顶端，底部工具仍可访问。

主要入口共用 `TavernApp` 的 NAV，与桌面、手机底栏一致；更多工具提供小说、任务、充值、VIP、模型预设、设置及安装应用。后台管理入口仅对 Super 显示，后台权限校验不变。

菜单采用非模态导航，不锁住背景或键盘。按钮公布展开状态，链接公布当前页；Escape 和关闭按钮收起菜单并返回触发按钮，外部点击或 Tab 移出收起菜单。放宽窗口进入桌面布局时关闭菜单。不同页面切换会替换导航实例，不承诺切换后始终聚焦旧触发按钮。

所有菜单链接仍调用原有 `navigate()`。未保存角色、未保存小说、正在回复或正在直播的保护不绕过；拒绝切换时菜单保留，原稿不变。本次实际验证了未保存角色保护，其他忙碌保护由未改动的导航逻辑继续承担。

实现文件：`src/components/dzmm/responsive-navigation.tsx`、`src/components/dzmm/tavern-app.tsx`、`src/components/dzmm/tavern.module.css`。验收资料位于 `output/xumeng/responsive-navigation-20261009`；使用原创隔离账户与 API，无真实模型、付款、签到或公开投稿。
