# XUMENG 多语言

XUMENG 现在支持以下五种界面与回复语言：

- English (`en`)
- 简体中文 (`zh-Hans`)
- 繁體中文 (`zh-Hant`)
- 日本語 (`ja`)
- 한국어 (`ko`)

语言选择位于顶部语言菜单，也可以在账号设置的「对话」部分修改。选择会随叙梦偏好设置保存，并通过云端偏好同步；旧记录没有语言字段时继续使用简体中文。首次打开时，如果浏览器语言是这五种语言之一，叙梦会采用对应语言。

语言设置会更新页面的 `document.lang`、主导航和发现区文案，也会传入角色聊天与行动建议的提示词，让模型使用选定语言生成内容。聊天提示词会带上语言路由标记：英语 `/en`、简体中文 `/zh-cn`、繁體中文 `/zh-tw`、日语 `/jp`、韩语 `/ko`。共享角色链接也会保留对应语言前缀。

公开卡的名称、标签、简介、性格、场景和开场白有独立的多语言翻译表；客户端通过后端翻译入口按语言加载，切换语言只替换展示副本，原始角色卡、用户输入、已有聊天历史和未翻译的提示字段继续保留。语言偏好随账户状态同步到 Cloudflare D1，URL 前缀（例如 `/jp`）始终优先于账户偏好。翻译缺失时回退到原文，避免因为翻译服务异常导致角色打不开。
