# 叙梦创作检查

预览发布新增本地创作复核，使用默认 xumeng-roleplay-authoring 的六个维度：角色辨识性、动机与主动行动、玩家可影响性、场景连续性、关系因果、信息与世界一致性。三个分组为人物与目标、开场与场景、关系与世界，均给出对应编辑入口。

自动部分只报告实际填写的模型字段、当前选中开场的非空角色/玩家消息数、启用和常驻世界书词条数。介绍不算模型设定，未填写独立场景也不能据此认定剧情不连贯；不以字数、关键词或填写数量推断质量。复核方向固定为待作者复核，真实剧情表现需实际试聊；本轮未调用模型。

非阻断兼容提醒复用实际宏展开逻辑。模型字段、各开场和启用世界书正文的未知占位符会作为字面文字保留；展示介绍和停用词条不检查。启用且非常驻的选择性词条需要辅助关键词才能激活；关键词中的占位符不会展开。提醒不改变保存/试聊/投稿门禁。

编辑入口仅切换步骤和专业模式并聚焦，不自动写内容、不标记草稿被修改。具体字段入口定位人物描述、故事场景或性格；通用入口落在步骤标题。作者填写后通过既有私人保存和云同步恢复，检查数据为派生事实，不保存新角色字段或总分。

关系复核允许不适用，不强制恋爱。好感、信任和戒备的实际会话初值/更新仍使用既有世界状态，写在卡内的初值不会配置会话数值；本轮没有增加自动数值绑定。

本地证据：7项纯检查回归，真实 CharacterStudio 组件隔离UI（主/备选开场统计、字段导航、场景更新、常驻词条提醒、带提醒保存、仅名称保存）；API请求0。正式页面另验收自建私人角色的复核显示、编辑和刷新恢复。详细记录见 output/xumeng/iteration/rounds/round7-20261007-ui.json。
