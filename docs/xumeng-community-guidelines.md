# 叙梦社区公约维护说明

公开页面：<https://xumengchat.top/community-guidelines>。首版为 `1.0`，更新时间 `2026-10-10`。

这是叙梦原创的社区参与与公开发布规则，参考了用户指定的 [DZMM 公约](https://www.dzmm.ai/community-guidelines) 的主题组织。没有复制竞品正文、处罚等级、客服联系方式或审核承诺。参考证据属于公开文档阅读，不能证明竞品实际审核、举报、申诉或封禁流程。

## 内容与适用范围

规则覆盖公开角色与封面、论坛主题和回复、任务交流，分为交流、发布、授权、内容安全、隐私、公平参与和举报七部分。页面标明成人使用要求，但此次没有新增自动年龄验证或修改注册的协议确认。

费用说明仍以充值页、生成报价和本人消费记录为准；此次不改变 Credit、VIP、模型、生成或直播的价格与权限。

## 单一内容来源

`src/lib/xumeng-community-guidelines.ts` 保存标题、描述、版本、日期及章节数据，并提供固定内容的 HTML 渲染函数。编辑公约只改此处，同时更新版本与日期。该函数没有用户输入，文字转义后输出；不要将用户提交的 HTML 放入这个渲染器。

`src/components/dzmm/community-guidelines.tsx` 和相邻 CSS 负责公共阅读页与可复用入口。正式 Vite 应用在 `cloudflare/dzmm-web/src/main.tsx` 根据 pathname 直接显示公约，不初始化 TavernApp 的账户或私人状态。仓库 Next 开发应用也有对应的 `src/app/community-guidelines/page.tsx`，生产验收以 Cloudflare 执行链路为准。

`cloudflare/dzmm-web/src/worker.ts` 为路径返回完整静态正文，并重写 title、description、分享标题和 canonical。HTMLRewriter 与浏览器复用同一内容源，关闭 JavaScript 时仍可阅读。内部读取首页壳使用无继承头的 GET，改写后去除首页的 ETag、Last-Modified 和长度；不能把首页的条件请求、Range 或 Cookie 转给壳读取。HEAD 返回空正文，非 GET/HEAD 返回 405；尾斜杠及大小写别名重定向到标准地址。公开 sitemap 包含该页。

## 入口与草稿

首页页脚、论坛标题区及发主题编辑器、创作者中心、登录/注册弹窗均提供“社区公约”链接。入口使用新标签页和 `noopener noreferrer`，不切换原页面，也不触发发布、认证或离开编辑器。请保留这个行为，避免读规则时丢失正在输入的内容。

## 与实际后台能力一致

- 论坛主题和回复提交后即公开；此次没有加投稿前审核。
- 正式账户可从论坛主题详情举报，涉及回复需在理由中标明作者和位置。管理员手动核查与删除内容；处理举报状态和删除内容是独立操作。
- 角色投稿有批准、退回、撤回和下架能力；退回原因可在创作者中心查看，修改后可再提交。小说工作台目前不自动公开。
- 对功能或处理有异议时，引导至论坛“站务与求助”。没有新增独立申诉工单、客服邮箱、自动封禁、自动审核或处理时限承诺。

若以后实现封禁、私密版权反馈、独立申诉等能力，再修改规则和入口；不要只在公约中声称功能已经存在。Telegram 反馈绑定尚未完成真实验收，首版不把它列为公众反馈渠道。
