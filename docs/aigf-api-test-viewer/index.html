和文档的差异

  • 路径仍是 /aigf/v1。
  • 剧本消息先返回 running，终态靠轮询。这次没接 WebSocket。
  • 完成时 usage 是 final，和文档一致。
  • 运行中已经能看到部分 token，正文仍为空。中途数字不能当最终账单。
  • 角色目录为空，文档示例的 character_id 20001 不能直接用。
  • 语音风格为空。
