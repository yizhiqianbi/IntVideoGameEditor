## 2026-10-03 角色创作与发布增量

创作者中心现在把私人草稿与公开投稿分成独立动作。保存会实际写入当前账户 D1，试聊使用编辑后的多条开场和模型设定；只有作者点击“提交审核”才创建投稿。提交前需要至少一条 AI 主开场，以及详细描述/性格/场景/系统指令中的至少一项，半成品仍可保存为私人草稿。

共享角色新增系统指令、历史后指令、对话示例、备选开场、多条初始 user/assistant 消息、世界书、展示介绍、图库和建议回复。上述字段经同一个 parser 校验，在导入、导出、浏览器恢复、D1 `characters.context_json`、聊天请求和批准后的公开卡之间保留；展示介绍和建议回复不作为人物系统设定注入。世界书仅把当前启用且触发的条目加入模型上下文，并受现有字符/UTF-8 总预算限制。既有 51 条采集/改写目录不变，也没有补造原站隐藏字段。

发布状态为 `pending`、`approved`、`rejected`、`withdrawn`。每次提交保存不可被后续私人编辑覆盖的规范快照，公开 ID 与私人草稿 ID 分开。新版本待审时，旧的 approved 版本继续公开；只有 Super 审核通过才切换公共目录。作者可撤回待审版本，作者或 Super 可下架；下架同时撤回待审更新，避免旧审核误将角色重新上架。退回必须填写修改建议。投稿与审核均用 publication `version` 条件更新，过期或并发操作返回 `409`；浏览器请求同时绑定 `accountId`，账号不匹配返回 `401`。

## 2026-10-03 任务中心与安装页增量
