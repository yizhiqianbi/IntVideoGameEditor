站点与统计链路

  • 托管：Cloudflare Pages 项目 hafyoung-cooling，创建于 2026-10-27，自定义域名 www.hafyoung-cooling.com（CNAME → hafyoung-cooling.pages.dev），线上返回 200，命中 Cloudflare 香港节点。
  • DNS 不在 Cloudflare：hafyoung-cooling.com 的 NS 是 ns1/ns2.myhostadmin.net（新网），所以 Cloudflare 侧没有对该域名的 Zone 级流量分析（请求数、带宽、缓存命中率都不在 CF 控制台）。
  • 统计是站内自建的：/k.js 上报到 /k/h，写入 D1 表 hits（pv / ev / end / bot 四类），本报告数据即来自该表，共 2,776 条、2026-11-01 起。
  • Cloudflare Web Analytics 未启用：页面里没有 CF 的 beacon.min.js，Pages 项目的 web_analytics_tag 为空。
  • 口径：pv/uv/事件只统计执行了 JS 的真人浏览器（无 Cookie，uv 用随机 vid 近似），广告拦截或禁用 JS 的访问会漏计；爬虫按 UA 单独计入 bot，不计入人工流量。停留时长只统计页面隐藏时上报的 end 事件，中位数为 11 秒更接近真实阅读，均值被少数超长会话（最长 3600 秒）拉高。

结论与建议

  • 想要 CF 侧的请求/带宽数据：需把域名 NS 迁到 Cloudflare（或在 CF 控制台另开 Web Analytics 并加 JS 片段）；目前站内 D1 统计已经能回答“谁来看、看什么、点了什么”。
