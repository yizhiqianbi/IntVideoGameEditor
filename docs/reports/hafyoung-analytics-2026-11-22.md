## 八、站点状态与统计链路

- Pages 项目 `hafyoung-cooling`，创建 2026-10-27，生产分支 `main`，构建目录 `dist`，Functions 已启用，绑定 D1 `hafyoung-stats` 与生产密钥 `STATS_KEY`。
- 自定义域名 `www.hafyoung-cooling.com`（CNAME → `hafyoung-cooling.pages.dev`），线上 200，命中 Cloudflare 香港节点。
- **DNS 不在 Cloudflare**：`hafyoung-cooling.com` 的 NS 为 `ns1/ns2.myhostadmin.net`（新网），因此 Cloudflare 控制台里没有该域名的 Zone 级流量分析（请求数、带宽、缓存命中率均无数据）。
- **Cloudflare Web Analytics 未启用**：页面中没有 `beacon.min.js`，Pages 项目的 `web_analytics_tag` 为空。
- 实际上报链路：`/k.js`（页面浏览、点击、视频播放、停留时长）→ `/k/h` → D1 `hits` 表，`k='bot'` 的请求单独标记，不计入人工流量。
- 口径：无 Cookie，uv 用随机 `vid` 近似；禁用 JS / 广告拦截的访问会漏计；停留时长仅统计页面隐藏时的 `end` 事件。
