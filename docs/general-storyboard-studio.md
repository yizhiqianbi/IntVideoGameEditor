# 通用分镜工作台

2026-10-06：公开工作台采用通用影视创作界面。空画布为“剧本、角色、分镜”，剧情风格为常规剧情、悬疑推理、轻松喜剧。剧本导演指令、参考场景、首帧和动画风格均移除成人向默认内容。

旧存档的 `sensual`、`explicit`、`mature` 风格读取为 `standard`。仅与旧版内置默认提示词完全相同的内容迁移为新默认；用户编写的文本、角色卡、素材、镜头和存档保留。

公开视频模型选择仅提供 H3。专用旧模型的适配器与历史任务不删除；旧存档手动选择此类模型时标示暂停，提交前提示改选 H3，不静默替换模型或提交任务。GPU 权重、服务配置及账户、支付设置未修改。
