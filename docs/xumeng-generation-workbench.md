## 持久化与恢复

`generation_jobs` 冻结模型参数、价格和汇率；`generation_credit_ledger` 保存唯一扣费/释放记录。0024 迁移将媒体消费和预留加进现有余额视图，保留所有充值、VIP、管理调整、注册赠送与聊天账本。聊天和媒体在同一个原子余额视图争抢可用额度，不允许分别看到同一余额后透支。

相同账号/requestId/指纹只由首个事务赢家提交一次供应商请求。浏览器在提交前按账号冻结请求编号、输入指纹及原批准额度；响应丢失或刷新后通过 `GET /v1/generation/requests/{requestId}` 只读核对，不使用新报价覆盖原授权，也不重发供应商请求。旧版没有额度的本地记录同样可只读核对。仅服务端明确返回 `generation_request_missing` 才重新报价并等待确认，仍沿用原编号以防迟到提交重复；用户显式点击“新任务”才创建新的编号。未知结果不自动重发。未知预留最多保留 30 分钟，超时释放且由站点承担无法核对的成本。每账号最多五个未完成任务。

图片请求同步生成并持久化；视频采用 [OpenRouter 异步任务](https://openrouter.ai/docs/guides/overview/multimodal/video-generation)，提交后保留 provider ID，每 30 秒核对进度，完成时只访问固定认证 content 接口。结果写入私人 R2 后，任务发布和唯一费用记录在同一 D1 事务里提交；响应丢失不能误删已提交的文件。轮询有租约和独立对象键，防止过时请求覆盖最新结果。原始描述和已提交任务始终在本人的任务历史。

素材只能由当前认证账号读取；R2 owner/job/fingerprint 和当前任务引用都核对。视频 GET Range 支持播放和拖动，网关只对精确合法私人素材路径传递 Range。终态软删除移除文件和可见历史，保留幂等身份和账本，已消费积分不会因删除返还。

草稿保存于当前浏览器标签页、当前账号的 sessionStorage，刷新和离开工具后恢复。2026-10-09 版将模板广场筛选、已查看模板、各模板字段独立保存，已应用模板和生成描述一并恢复；这条为旧版数据契约记录。已提交任务和结果是 D1/R2 跨设备持久化，浏览器草稿不声称跨设备同步。

2026-10-10 的主草稿键仍为 `xumeng-generation-draft:{accountId}`，新版采用 `schemaVersion: 2`：

| 字段 | 含义 |
|---|---|
| `kind / modelId / aspectRatio / duration` | 当前图片或视频及生成设置；界面只提交实际模型支持的比例和时长。 |
| `templateId / editorMode` | 当前模板来源；`editorMode` 为 `template` 或 `legacy`。旧自由文本、手改描述及无法可靠还原的模板内容按 `legacy` 保留。 |
| `templateDrafts` | 以目录模板 ID 为键，各项为 `{ values, additionalRequirements }`；只导入该模板允许的字段，每项最多 1,000 字。不同模板的参数分别保留。 |
| `prompt` | 模板模式下为当前编译描述快照，旧描述模式下为原始完整文本；最终描述最多 4,000 字。 |
| `workspaceMode` | `templates` 或 `create`，记录所在工作台视图。 |
| `useReferenceImage / referenceImage` | 是否使用参考图及已验证的私人图片编号、元数据；不存原图 base64。 |

读取旧 `xumeng-generation-library:{accountId}` 的 `drafts` 作为可继续编辑的模板参数；有效新版主参数优先，不用旧库示例覆盖现有 `prompt`。模板广场只继续维护自己的类型、用途和搜索筛选，写入时保留旧字段草稿及其他元数据。没有可靠参数、模板与种类不符，或当前编译结果与保存的描述快照不一致时，回退为保存的完整旧描述，不自动改写用户内容。参数尚未填完整的新版稿件仍保留字段，不能报价；不把空的新工作台迁移成新的自由创作入口。
