# 叙梦对话开场

更新：2026-10-05（Asia/Shanghai）。此前 41 张公开导入卡保留了介绍原文，但原始开场字段为空；其中仅一张有独立公开渲染开场补充。进入其余角色的新对话时，聊天区没有消息。角色介绍原本已经进入模型设定，缺少的是可见开场。

现在前端与后端使用统一的对话开场规则：优先保留作者的多条初始消息、主开场或所选备选开场；缺少开场时，显示卡片已有的场景或介绍，标为「故事背景」；没有这些字段的私人角色得到一句中性起始提示。来源卡片和介绍字节保持不变，不把备用内容写回原始开场字段，也不使用作者备注或展示用 introduction 作为模型输入。

当前账户与目录加载完成后，只补齐零消息且角色仍可找到的会话。已存在的历史和未知角色记录保留。修复幂等，不会在刷新、切换或云端保存后重复添加消息。新对话先显示长开场顶部，发生实际交流后继续跟随回复滚动。

共享实现：[对话开场](../src/lib/dzmm-conversation-opening.ts)；页面：[TavernApp](../src/components/dzmm/tavern-app.tsx)；后端创建：[data.ts](../cloudflare/dzmm/src/data.ts)。开场和用户首条消息共同进入已有的提示词与剧情记忆链，不额外调用模型生成开场。
