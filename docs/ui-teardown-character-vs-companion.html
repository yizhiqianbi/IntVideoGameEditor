陪伴产品：首页不是广场。

Replika

一个账号一个伴侣。没有公共角色榜，也没有把她导出成卡。界面重心是和这一个人的连续聊天、电话和近况。

Kindroid

可以有几位。写死的背景、后来记下的关键记忆、日记，是三本不同的本子。背景像卡，记忆像关系。

Nomi

每位是一段会自己长的关系，会主动发消息。群聊是把几位陪伴放在一起，不是把几张公开卡拼成剧本。

酒馆不做陪伴卡，它把材料拆开。

SillyTavern 的界面是本地角色库加工具栏，不是广场。它把「能交给别人的」和「只属于你的」分成四本。

本子界面里在哪跟着谁走
角色卡角色管理。导出就是一张卡或一张带卡的图。任何拿到这张卡的人。
Persona你的名字、头像、自我介绍。可以锁在某一场或某张卡上。你。换角色还在。
世界书关键词触发。可绑在卡、Persona，或只绑这一场聊天。看你绑在哪。
这场记录聊天气泡本身。只属于这一场，不进卡。

角色卡每次发消息都会整段送进模型。世界书只在关键词出现时送。所以「她是谁」放卡里，「这个镇的巷子」放世界书，「你上夜班」如果写进可分享的卡，下一个下载的人也会变成夜班。
