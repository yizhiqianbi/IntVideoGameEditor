支持哪些远程连接方式

下面这些交付时都已经装好、配好，选顺手的用就行。

方式情况适合
UU 远程已预装，交付默认远程桌面，看到完整的 macOS 画面，日常使用首选。
ToDesk已预装远程桌面，作为第二条连接通道。
RustDesk已预装开源的远程桌面，习惯用它的可以直接用。
Tailscale + SSH已预装，远程登录已打开在你的电脑和 Mac 之间组一个私有网络，再用 SSH 连接，适合命令行和开发。
  • 建议至少保留一个远程桌面工具能用，其他方式出问题时还有备用通道。
  • 用 SSH：你的电脑也装上 Tailscale 并加入同一个网络，然后用 ssh 加系统账号和 Mac 的 Tailscale 地址连接。接入需要协助的，联系客服。
  • 不要把 Mac 设成 Tailscale 的出口节点（exit node），也不要用任何工具把它当代理给别的设备上网，这违反服务条款。

第一次怎么连接美国 Mac

交付时，我们会发给你这台 Mac 的连接信息：UU 远程和 ToDesk 的设备码与连接密码，以及 macOS 的系统账号（普通用户，不是管理员）。然后：

  1. 1在你自己的电脑或手机上安装 UU 远程或 ToDesk 的客户端。
  2. 2输入设备码和连接密码，连上 Mac 的桌面。
  3. 3用系统账号登录 macOS，建议马上把密码改成你自己的。
  4. 4在 UU 远程和 ToDesk 里，把连接密码也改成你自己的。
  5. 5打开 Claude 桌面端和终端里的 Claude Code，确认账号已经登录、能正常对话。
  6. 6检查网络是否为美国住宅 IP。有任何问题，请在交付当天联系客服。

交付时预装了什么

  • Claude 桌面端和 Claude Code，已登录你这一档的 Claude 账号。
  • 远程工具：UU 远程、ToDesk、RustDesk、Tailscale，SSH（远程登录）已打开。
  • 开发工具：Xcode、Homebrew（交给你的账号，直接 brew install，不需要管理员），以及 Git 等常用开发工具。
  • 缺什么用 Homebrew 装；需要管理员权限才能装的，联系客服。

使用中请不要做的事

你的账号是普通用户，网络、系统安全这类设置本来就改不了。剩下几件请不要做：

  • 不要关机。Mac 关机后远程连不上，要等现场开机。
  • 不要修改 Claude 账号的订阅或付款信息，也不要换成别的 Claude 账号，详见服务条款第四条。
  • 不要把 Mac 当代理、中转或对外服务用。

需要管理员权限的软件或设置（比如安装 .pkg 安装包、改系统设置），联系客服，我们替你装好或改好。用 Homebrew 装软件不需要管理员，直接 brew install 就行。

Apple ID 与退租前的准备

  • 可以在 Mac 上登录你自己的 Apple ID，建议用一个专门的 Apple ID，不要用存着照片和通讯录的主账号。
  • 我们不会向你索要 Apple ID 或密码。以 CCRent 名义索要的，都不是我们发的。
  • 登录 Apple ID 后，请保持「查找我的 Mac」关闭。

服务到期前，请按顺序做完：

  1. 1备份代码和文件到你自己的云盘或代码仓库。
  2. 2在「系统设置」里退出你的 Apple ID。
  3. 3确认「查找我的 Mac」已关闭。
  4. 4退出你登录过的其他账号（浏览器、iCloud 钥匙串、第三方应用）。

如果没有退出 Apple ID 并关闭「查找」，Mac 重置后开机会要求输入你的 Apple ID 密码才能激活，这台 Mac 就无法重置。到期后 Mac 会被清空，数据无法恢复。

远程桌面卡顿、延迟高怎么办

Mac 接在美国住宅 IP 上，远程画面流不流畅，主要看你本地到美国的线路。卡顿时可以按这个顺序试：

  1. 1电脑改用有线网络，或换到信号更好的 Wi-Fi。
  2. 2在 UU 远程或 ToDesk 的设置里调低画面分辨率或帧率。
  3. 3关掉本地占用上传带宽的应用，比如网盘同步、视频通话。
  4. 4换另一个远程工具试试，比如从 UU 远程换到 ToDesk。
  5. 5写代码为主的话，用 Tailscale 加 SSH 走命令行，几乎不受画面卡顿影响。
  6. 6还是不理想，联系客服帮你排查线路。

怎么传文件、复制粘贴

  • UU 远程和 ToDesk 都自带文件传输和剪贴板同步，在连接窗口的工具栏里可以找到，具体入口以客户端为准。
  • 代码建议直接用 Git 推拉，不用在两台电脑之间来回拷。
  • 大文件建议走你自己的云盘，或者用 Tailscale 加 scp、rsync 传。

Claude 账号

  • Max、Ultra 套餐：Claude 桌面端和 Claude Code 已经登录你的 Claude Max 或 Ultra 账号，直接用就行。仅 Mac 租赁：Claude 已经装好，登录你自己的账号即可。
  • 额度用完时，按 Anthropic 的规则会定时恢复。选了 Max 经常不够用，可以升级到 Ultra。
  • Max、Ultra 套餐不含质保，账号被停用后不补号。之前已购质保的订单，当前服务期内账号在正常使用中被停用，联系客服补号，耽误的天数顺延到服务期末。
  • Max、Ultra 套餐的账号订阅费由我们代付，不要修改订阅或付款信息，也不要换成别的 Claude 账号。

安全与隐私

  • 全新环境：每台 Mac 交付时都是全新、干净的 macOS 环境。
  • 一人一机：每台 Mac 只租给一位客户独享，不与他人共用，使用美国住宅 IP（千兆家宽）。
  • 账户自主：可以修改系统密码，登录你自己的 Apple 账户。
  • 远程连接：用 UU 远程、ToDesk 等工具连接，连接密码可以改成你自己的。
  • 退租清空：服务结束后 Mac 会重置，所有数据清空，无法恢复。
  • 管理员权限：由我们保留，只用于安装需要管理员权限的软件、修改系统设置和维修。我们只在你请求协助、提前告知的维护，或已购质保的订单经你授权取证时登录。

交付后建议：

  1. 1把 macOS 账号的密码改成你自己的。
  2. 2在 UU 远程里把这台 Mac 的连接密码改成你自己的，不要发给他人。
  3. 3退租前删除本机上的代码仓库密钥和访问令牌。
