价格常见问题

海外 Mac mini 租一个月多少钱？能直接用 Claude 吗？

仅 Mac 租赁 $159/月，Max $360/月，Ultra $518/月。三个套餐都是一台专属 Mac mini M4 加千兆光纤家宽 IP，Claude Code 已经装好。Max 和 Ultra 另外开通好了 Claude 订阅，交付后直接能用；仅 Mac 租赁不含账号，需要登录你自己的 Claude 账号。

我已经有 Claude 账号，可以只租 Mac 吗？

可以，选仅 Mac 租赁，$159/月。Mac、千兆光纤家宽 IP、预装的 Claude 桌面端和 Claude Code、24 小时售后都和 Max、Ultra 套餐一样，只是不含 Claude 账号，由你登录自己的账号使用。账号本身的订阅和停用由你自己负责。

几个套餐怎么选？

已经有 Claude 账号，选仅 Mac 租赁。需要我们开通账号的话，Max 和 Ultra 只差 Claude 的用量额度和响应优先级：每天长时间跑 Claude Code 选 Ultra；拿不准就先选 Max，之后随时可以升级。一次要租好几台，选多台 / 团队，价格单独谈。

服务期从哪天开始算？

从交付当天开始算，付款到交付之间的等待不计入。维修耽误的天数，顺延到服务期末。

中途可以升级吗？

可以从 Max 升级到 Ultra，按剩余天数折算，补齐两档差价，具体金额由客服核算。

能开发票吗？税点多少？

可以开发票，需另加税点，具体税点请咨询客服。

不想续费了怎么办？

到期不续即可，不需要额外操作。服务期开始后原则上不退款，确有特殊情况请联系客服协商。到期后 Mac 会重置，请提前备份数据。

租多台有优惠吗？

有，按台数和时长一事一议，请直接联系客服。
