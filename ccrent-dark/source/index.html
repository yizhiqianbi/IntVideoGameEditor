OAuth 回调里的 state 校验
DOAuth 回调为什么一定要校验 state 参数？

为了防止登录 CSRF：攻击者可以把自己账号的授权码塞进你的回调，让你在不知情的情况下登录到他的账号。

做法是发起授权前生成一个随机 state，存进会话，回调时比对：

if (query.state !== session.oauthState) reject()

租的 Mac mini 包含 Claude 订阅吗？

看你选哪个套餐。Max（$360/月起）和 Ultra（$518/月起）包含：我们协助你以本人身份通过官方渠道开通 Claude Max 或 Ultra，交付时已经开好，不用你自己折腾注册和付款。仅 Mac 租赁（$159/月）不含账号，适合已经有 Claude 订阅的人，登录自己的账号就能用。

一般的 Mac 云租赁只给机器，网络和 Claude 都要自己配。CCRent 的每台 Mac 都接当地千兆光纤家宽 IP，Claude Code 已经装好；只租 Mac $159/月，用你自己的账号。选 Max 或 Ultra 套餐，我们再把 Claude 订阅开通好一起交付。
