# H3 换脸视频 prompt 对照实验（2026-11-19）

同一组输入：参考图 = bob 头金发女性（白上衣），参考视频 = 双丸子头女性 5 秒夜晚街道素材；
duration 5 / 720P / ratio adaptive；每条 prompt 生成 1 次（P3 复测 3 次）。

## 结果

| 编号 | Prompt 类型 | 身份换成参考脸 | 保留原视频场景 | 备注 |
| --- | --- | --- | --- | --- |
| P1 | 现网主模板（分工 + 不要保留原脸） | ✅ | ❌ 画面按参考图重生成（室内/黑西装） | 否定句无效 |
| P2 | 身份独占（否定 + 全替换） | ❌ 保留原角色 | ✅ | 否定句反而保留原角色 |
| **P3** | **具体可见描述（目标外貌 + 原场景 + 镜头/动作）** | **✅ 2/3** | **✅ 2/3** | **最好：2 次成功、1 次保留原角色** |
| P4 | 极简指令 | ✅ | ❌ 场景重生成 | 同 P1 |
| P5 | 英文指令（含 do not keep 否定） | ❌ | ✅ | 否定句反向 |
| P6 | 通用模板（保留她的脸/发型 + 描述场景） | ❌ | ✅ | 1/1 失败，待更多样本 |
| P7 | 混合模板（P3 + 排斥原角色） | ❌ | ✅ | 加了否定句就失败 |

P3 三次抽帧：成功、失败（保留原角色）、成功。动作/眨眼/头角度与源视频基本对齐
（见 `motion-compare.jpg` 成对帧）。

## 结论

1. **H3 没有 negative 字段，否定句会反向引导**：写「不要保留参考视频里原来的脸和身份」「禁止出现原角色」
   这类句子，结果反而更容易保留原角色（P2/P5/P6/P7 全部如此）。这条和
   `h3-prompt-standardizer` 的规则一致：不要用否定式写故障词。
2. **只描述目标、不描述场景 → 画面被参考图重生成**（P1/P4）：H3 会把 reference_image 当成画面来源。
3. **「具体可见描述」最有效（P3）**：同时写清
   - 目标人物的可见特征（发色/发型/服装），
   - 原视频的场景与镜头（夜晚街道、正面、镜头固定），
   - 参考视频只负责动作和节奏；
   身份和场景都更容易同时保住，实测 2/3。
4. **没有 100% 稳定的 prompt**：P3 也有 1/3 失败。工程上要么 best-of-2/3 多跑几条再挑，
   要么换脸场景直接走 huanlian。

## 可执行模板（P3 风格）

```text
参考图里的{目标人物可见特征：发色、发型、服装}，站在{原视频场景描述}，{镜头与构图}，
{动作/表情节奏，与参考视频一致}，写实摄影，画面里只有她一个人。人物是虚构的成年人，二十一岁以上。
```

注意：模板里的目标外貌和场景描述必须按实际图片/视频填写，不能写死；可先用识图模型描述参考图
和原视频首帧，再拼模板。
