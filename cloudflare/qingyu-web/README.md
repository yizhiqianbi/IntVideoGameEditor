## 启动

在本目录运行 `npm ci`、`npm run db:migrate:local`、`npm run build` 和 `npm run dev:worker`。另一个终端运行 `npm run dev`，打开 `http://127.0.0.1:5186`。独立 Worker 位于 `127.0.0.1:8796`，使用本项目自己的本地 D1、R2 和 Cookie `qingyu_session`。

模型与内容检查仅从本项目服务端环境读取，示例见 `.env.example`。未配置的服务明确返回不可用，不伪造 AI 回复。用户已选择复用现有供应商账户；本地 Worker 的独立 `.dev.vars` 已接入 Qwen 对话及 Qwen3.6 Plus 语义/图像检查，密钥不进入前端或文档。`scripts/configure-local-provider.mjs` 用于显式指定现有配置文件来创建独立配置，绝不写回原文件。

## 独立结构

- `engine/src/`：冻结复制的完整业务模块，修改仅发生在副本。
- `engine/cloudflare/dzmm/`：独立后端、迁移和回归测试。
- `engine/cloudflare/dzmm-web/`：独立网关、通话与语音实现。
- `engine/cloudflare/qingyu-companion/`：原生陪伴独立宿主与测试。
- `engine/companion-native/`：原生记忆引擎的干净构建上下文，不含旧账号实例或记忆。
- `src/worker.ts` 和 `src/server/`：组合完整业务，并执行输入、输出、发布、图片及陪伴内容检查。
- `src/main.tsx`：完整应用实际入口。
- `src/otome.css` 与 `engine/src/components/dzmm/otome-home.*`：新视觉系统。
- `public/art/`：内置 imagegen 生成的原创角色立绘。

原版源码基线在 `evidence/full-engine-baseline.json`。没有绑定原版生产数据库、R2、域名或陪伴实例；发现原目录并行变更时保留原文件，不覆盖或回滚。
