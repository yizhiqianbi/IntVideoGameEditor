# 晴屿人物卡 · 2026-10-24

本轮仅更新晴屿独立副本。四个人物 ID、创建日期与立绘保留；旧聊天、用户自定义角色和陪伴风格不批量改写。新建故事使用新开场，已有故事继续原来的历史。

| --- | --- | --- |

每人有完整经历、当下目标、可观察的缺点、两位配角、生活喜好、关系推进方式、四组对白示例、一个主开场与两个独立备选开场、十条世界书。世界书包括三条常驻相处与语气设定、七条人物生活或项目线索。职业和项目不是唯一话题，初始事件能够结束。

所有人物遵守全年龄要求。主动担当体现在自己的行动与责任里；用户拒绝安排、要求独处或转换话题时跟随实际选择。关系不预填数值或规定聊天轮数，不将示例当历史，不替用户写重要行动与同意。

## 来源与文件

采用 [foreverse-app/character-card-skills 的 character-card-author](https://github.com/foreverse-app/character-card-skills/tree/main/skills/character-card-author)（内容许可 CC BY 4.0）的角色卡创作方法，并结合本地 `xumeng-roleplay-authoring` 的角色状态、情节推进及实际导入校验流程。技能已安装在 `/Users/pencil/.codex/skills/character-card-author/`，来源与指纹见 `skill-source.json`。四个人物文字均为本项目原创，没有复用外部人物卡或图片。

写作方法已按晴屿改编：不采用成人标签、年龄差强制要求、未实现的状态数值、HTML 面板、正则插件或平台不支持的宏。未运行外部评分器，也不将测试通过解释为人物质量分数。

- 实际数据源：`engine/src/lib/qingyu-catalog.ts` 与 `engine/src/lib/qingyu-cards/`。
- `cards/*.md`：可阅读的人物设定稿，由数据源生成。
- `cards/*.qingyu.json`：本地编辑与导入格式。
- `public/character-cards/*.json`：SillyTavern `chara_card_v2` 下载件，包含世界书、示例、系统提示和备选开场。
- `public/character-cards/index.json`：下载索引。

修改数据源后运行 `npm run cards:export`；构建也会自动执行。导出脚本使用项目真实导入器往返检查，避免只生成外观相似的 JSON。页面的“查看角色设定”可展开完整背景，主页面保持简洁。备选开场在卡文件和编辑器中提供，本轮没有新增前台开场选择器。

陪伴的陆时予、沈聿、季临川三个默认风格也已细化。默认字段遵守宿主长度限制；新对话读取这些默认值，已有自定义风格保留。本轮没有更换原生容器、批量覆盖旧实例设置或复测完整原生记忆流程。

## 验证与实际范围

四张 V2 卡经过实际导入器和提示词组装校验，十二个开场均通过，证据为 `evidence/card-validation-qy-*.json`。`scripts/validate-qingyu-card.mjs` 仅把本地技能校验器的旧目录路径适配到独立引擎布局；第一次未经适配的路径失败记录保留。主应用 44 项检查通过，生产构建与类型检查通过。

真实供应商抽样用于发现问题，不是自动文风评分。较早的 Qwen3 30B 两轮均返回可审核内容，但出现把角色喜好写成用户喜好、无依据回忆、只需安慰时转成邀约等问题；原输出保留。加强每轮事实约束后，又用同一账户的 Qwen3.6 Plus 抽测八种输入，安慰、给独处空间、区分证据等表现改善。仍观察到隐私撤回流程写得过细、半年跳时沿用旧季节等问题，长线连续性不能据此宣称全部通过。见 `evidence/character-cards-live-*.json` 与 `character-cards-review.json`。

晴屿主站默认及命名 Qwen 选项改为 Qwen3.6 Plus，现有供应商账户不变，原生容器模型不变。首轮真实主站短回复请求没有生成可审核正文；可选思考消耗短输出预算与官方说明一致，故关闭该模型可选思考后复测，不提高用户设定的回复长度。官方型号与费用元数据存于 `evidence/character-cards-model-metadata.json`，包含长上下文和缓存写入上限；当前支付与用户计费仍关闭。实际主站端到端结果单独记录在 `evidence/character-cards-production.json`，不与供应商直连抽样混为一谈。

最终生产检查：四份下载均返回200且与本地导出件哈希一致，独立验收账号登录200，实际主站对话返回200并由现有世界流解析器读取到正文；未覆盖账号故事历史。Codex 内置浏览器已展开沈聿的人物经历与生活，页面预览为 `evidence/character-cards-page.jpg`。
