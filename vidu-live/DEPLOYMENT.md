# 表演指令模式

你填写回应方向、情绪和动作，S2 理解意图后自行组织语言并表演。不会逐字朗读输入，也不使用独立的 TTS 或组件版。

数据流：观众弹幕 / 你的表演指令 → Vidu realtime（type 99 表演指令）→ S2 生成语音和画面 → 浏览器 RTC 播放。

弹幕 `/api/danmaku` 直接通过 type 99 发送到 S2，触发自然回应。执行 `/api/execute` 接受 `{intent,emotion,motion}`，至少填写一项。主播设定补充“按意图回应，不朗读指令”。模型实际措辞和动作仍存在不确定性。

## 访问与部署

后端：4090_med 的 `/data/zrc/dyt/vidu-live/`。
systemd 用户服务：`vidu-director.service`，只监听 `127.0.0.1:8787`。
本机通过 SSH 隧道访问 `http://127.0.0.1:8787/`。

```sh
ssh -N -L 127.0.0.1:8787:127.0.0.1:8787 4090_med
ssh 4090_med 'systemctl --user status vidu-director.service'
```

上传主播图，填写主播设定和 S2 音色，然后开启演练或真实直播。填写回应方向、情绪、动作并点击“执行表演”。演练只验证指令，不生成声音或视频。真实直播需要 Vidu Key，不需要另配 RTC。

Key 通过连接设置保存在服务进程内存；重启需重新填写，也可保存在服务器 `.env`（权限 600）。服务不保存 SSH 密码。

此模式仍调用 S2 自动对话，仍按直播时长计费，不宣称节省 token 或直播 credit。没有本地直播时长上限；保留页面关闭、失联及初始化失败后的连接清理。平台有效期仍适用。

先前安装的 Piper 模型和 Python 环境未启动、不参与当前流程；可按需另行清理。
